# Project 1: Number Guessing Game

A console-based Number Guessing Game developed in Java as part of my DecodeLabs Java Programming Internship.

## Project Overview

The program generates a random number between 1 and 100. The user must guess the number, and the program provides feedback after every attempt.

- If the guess is higher, it displays Too High.
- If the guess is lower, it displays Too Low.
- When the guess is correct, it displays a success message and the number of attempts.

## Features

- Random number generation
- User input using Scanner
- High/low hints
- Attempts tracking
- Score calculation
- While loop and conditional statements

## Technologies Used

- Java
- Random Class
- Scanner Class
- Loops
- Conditional Statements

## How to Run

1. Compile the program:

javac NumberGame.java

2. Run the program:

java NumberGame

## Learning Outcome

This project helped me practice loops, conditional logic, random number generation, and user interaction in Java.
