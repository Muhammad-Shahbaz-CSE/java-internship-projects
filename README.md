# DecodeLabs Java Programming Internship

Welcome to my Java Programming Internship Projects repository.

This repository contains the projects I developed during my Java Programming Internship at DecodeLabs. These projects helped me improve my programming logic, problem-solving skills, and understanding of Java fundamentals and Object-Oriented Programming.

## 🚀 Projects

### 📌 Project 1: Number Guessing Game

A console-based game developed in Java where the program generates a random number between 1 and 100. The user must guess the number with the help of high and low hints.

#### Features
- Random number generation
- User input using Scanner
- High and low hints
- Attempts tracking
- Score calculation
- Loops and conditional statements

#### Concepts Used
- Random Class
- Scanner Class
- While Loop
- If-Else Statements
- User Input Handling

---

### 📌 Project 2: Student Grade Calculator

A console-based Java application that accepts the number of subjects and marks obtained in each subject. It calculates total marks, percentage, and grade, and displays a student report.

#### Features
- Number of subjects input
- Marks validation between 0 and 100
- Total marks calculation
- Percentage calculation
- Grade assignment
- Formatted student report

#### Grading Criteria

| Percentage | Grade |
|------------|-------|
| 90 or above | A |
| 80–89 | B |
| 70–79 | C |
| 60–69 | D |
| Below 60 | F |

#### Concepts Used
- Arrays
- For Loop
- While Loop
- Input Validation
- Type Casting
- Conditional Statements
- Formatted Output

---

### 📌 Project 3: ATM Interface

A console-based ATM Interface developed in Java using Object-Oriented Programming concepts.

The application allows users to check their balance, deposit money, withdraw money, and exit the ATM system.

#### Features
- Check account balance
- Deposit money
- Withdraw money
- Insufficient balance validation
- Invalid input handling
- Interactive ATM menu
- Account management

#### Concepts Used
- Object-Oriented Programming (OOP)
- Classes and Objects
- Encapsulation
- Constructors
- Private Variables
- Methods
- Switch Statements
- Loops
- Input Validation
- Scanner Class

#### Main Classes
- `BankAccount` — Handles account balance and transaction rules.
- `ATM` — Handles menu, user input, and messages.
- `ATMInterface` — Main entry point of the application.
