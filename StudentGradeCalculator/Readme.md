# Project 2: Student Grade Calculator

A console-based Student Grade Calculator developed in Java as part of my DecodeLabs Java Programming Internship.

## Project Overview

The program accepts the number of subjects and marks obtained in each subject. It calculates total marks, percentage, and grade, then displays a student report.

## Features

- Accepts number of subjects
- Validates subject count
- Accepts marks between 0 and 100
- Validates marks
- Calculates total marks
- Calculates percentage
- Assigns grades
- Displays a formatted student report

## Grading Criteria

| Percentage | Grade |
|------------|-------|
| 80 or above | A |
| 70–79 | B |
| 60–69 | C |
| 50–59 | D |
| Below 50 | F |

## Technologies Used

- Java
- Scanner Class
- Arrays
- For Loop
- While Loop
- Input Validation
- Conditional Statements
- Formatted Output

## How to Run

1. Compile the program:

javac StudentGradeCalculator.java

2. Run the program:

java StudentGradeCalculator

## Learning Outcome

This project helped me practice arrays, loops, input validation, percentage calculation, grading logic, and formatted console output in Java.
